# Adapted TUBELEX example code

`examples/tubelex-tokenize.py` adapts the English apostrophe, number replacement
and word filter functions from TUBELEX, copyright (c) 2022–2024 Adam Nohejl,
under BSD-3-Clause. The accompanying LICENSE retains the original terms.

Source: https://github.com/naist-nlp/tubelex/tree/7cb5fb36add76b83a266d1967536e1a1d3faa513

The optional TUBELEX frequency table is downloaded separately. Its archive
contains its own source, transformation and license records.
